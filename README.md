# 📝 Responsive Personal Portfolio — README

## *AI Tool Used*
I used *Lovable.dev* to generate the initial template for my personal portfolio website.

---

## *What I Edited Manually*

After generating the basic layout using the AI tool, I manually improved many parts of the project to meet the assignment requirements and to make the design cleaner and more responsive.

### ✅ *HTML Changes*
- Replaced all template text with my own content.
- Updated the hero section with my details: *Sri Varsha*.
- Added clean content for *About, **Skills, and **Contact* sections.
- Improved the navigation structure and internal links.
- Added footer links (GitHub, LinkedIn, Email placeholders).
- Ensured semantic and easy-to-read HTML structure.

### ✅ *CSS Changes*
- Designed a *mobile-first* layout for smooth responsiveness.
- Added media queries for:
  - *Tablet (768–1023px)*
  - *Desktop (≥1024px)*
- Styled:
  - Sticky header with blur effect  
  - Mobile hamburger menu  
  - Buttons (primary + ghost)  
  - Hero section animation  
  - Skills cards with hover effects  
  - Clean footer layout  
- Customized colors, gradients, borders, shadows, and spacing.
- Improved typography, alignment, and overall UI polish.

### ✅ *Responsiveness Fixes (As Required by Masai)*

| Device | What Works |
|--------|------------|
| *Mobile (≤767px)* | Hamburger menu, single-column layout, 1-column skills grid |
| *Tablet (768–1023px)* | Horizontal navigation, 2-column skills grid, improved section spacing |
| *Desktop (≥1024px)* | Full wide layout, 3-column skills grid, centered hero section |

The webpage has *no horizontal scrolling* and adapts smoothly on all screens.
